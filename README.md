# ГТ Монитор — демонстрационный редизайн

Статический многостраничный прототип. Тексты, логотип, контакты и фотографии взяты с действующего сайта `gtmonitor.ru`; структура и визуальное оформление сделаны заново.

В прототип входят:

- главная страница;
- каталог услуг;
- направления «Обследование», «Проектирование» и «Документация»;
- выполненные работы;
- страница компании;
- контакты.

## Локальный просмотр

Откройте папку через любой статический сервер, например:

```bash
python3 -m http.server 4173
```

После этого страница доступна по адресу `http://localhost:4173`.

## Публикация на Cloudflare Pages

Проект не требует сборки. В настройках публикации укажите:

- Build command: оставить пустым
- Build output directory: `/`

Форма обратной связи демонстрационная и не отправляет данные.
